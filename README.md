🧮 BMI Calculator

A sleek and user-friendly web application designed to calculate your Body Mass Index (BMI) based on your height and weight. Built with HTML, CSS, and JavaScript, this tool provides instant feedback on your BMI and categorizes it according to standard health guidelines.​


🚀 Features

Instant BMI Calculation: Enter your height and weight to receive immediate BMI results.

Health Categorization: Automatically classifies your BMI into categories such as Underweight, Normal, Overweight, or Obese.

Responsive Design: Optimized for various devices, ensuring a seamless experience on desktops, tablets, and smartphones.

Clean Interface: Minimalistic design for easy navigation and readability.​


🛠️ Technologies Used

HTML: Structuring the web content.

CSS: Styling the application for visual appeal.

JavaScript: Implementing functionality and interactivity
